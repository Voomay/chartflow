# Installable Chart Replay

The manifest provides standalone launch, theme colours and PNG icons (including a maskable icon). A compact install invitation appears after six seconds, or when the browser offers installation. Dismissal pauses invitations for seven days. Installed standalone windows suppress it. Supported browsers use their native install dialog after the user clicks; others receive platform-specific instructions. No operating-system notification permission is requested: this is an in-app install invitation, not push messaging.

The production service worker caches only the offline information page. Navigations use the network, with that page as fallback on connection failure. API responses, candles, account data and the app shell are never cached by the worker. Market data and trading require a connection. No automatic worker takeover or page reload interrupts an active session. Normal browser storage still holds the existing local account/session data; this does not add cloud sync.

Use HTTPS in production (localhost is also trusted). `npm run build` followed by `npm run preview -- --host 127.0.0.1 --port 3002` exercises production registration. Vite development deliberately does not register the worker, avoiding stale development assets. Check manifest and icons, install on Chrome/Edge and Android, and use Share → Add to Home Screen on iOS. The browser controls install eligibility and whether it offers a native prompt. Test offline reload after the first successful online visit; it should show the reconnect page, never old live quotes.
